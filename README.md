# Week 2 – Student Grade Calculator

## Project Overview

This project is a simple **Student Grade Calculator** created using Python as part of Week 2 of my Data Science Internship.

The program takes the student's name and marks as input, calculates the grade, and displays an encouraging message.

## Objectives

* Practice `if-elif-else` statements
* Practice comparison operators
* Use functions in Python
* Use `while` loops
* Handle invalid inputs
* Practice basic error handling

## Features

* Takes student name as input
* Takes marks between 0 and 100
* Calculates the student's grade
* Displays an encouraging message
* Rejects marks below 0 or above 100
* Handles non-numeric input
* Uses a `while` loop for invalid inputs

## Technologies Used

* Python 3
* VS Code / Python IDLE

## Grading System

| Marks  | Grade |
| ------ | ----- |
| 90–100 | A     |
| 80–89  | B     |
| 70–79  | C     |
| 60–69  | D     |
| 0–59   | F     |

## How to Run

1. Install Python 3.
2. Open the project folder.
3. Run the following command:

```bash
python student_grade_calculator.py
```

4. Enter the student's name.
5. Enter the marks.
6. The program will display the grade and message.
